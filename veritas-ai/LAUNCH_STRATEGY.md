## Demo Script (2 minutes)

1. **Open landing page** → Show premium UI, explain tagline
2. **Navigate to Dashboard** → Click microphone, say "Is Elon Musk buying TikTok?"
3. **Wait for results** → Show truth score gauge, explainability panel, voice readout
4. **Open Timeline** → Show historical verifications
5. **Show Extension** → Right-click a tweet, show overlay
6. **Show Developer Portal** → Copy API key, run curl command
7. **Show Feedback** → Submit a correction, explain RLHF pipeline
